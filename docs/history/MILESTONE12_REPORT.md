## Which constitution rules became code

1. **Chrome hierarchy** — `--color-app-titlebar` (defaults to oxblood) is now the shared
   application-window title-bar token; OS-level chrome (top bar, dock, boot, Command Palette)
   stays navy because none of those render through `.cattipu-window-frame`. Architect's own
   content-level oxblood retint (M11) is kept as a documented, narrower exception — its
   now-redundant title-bar half of the override was removed.
2. **Window controls** — 24×24 (`--window-control`, unchanged) molded `[_] [□] [X]`. `Layers` is
   gone; `Square` renders `[□]` for both maximize and restore states; behavior unchanged.
3. **Font roles** — six named roles (Menu/Window Title/Labels/Code/Status Bar/Hero) map onto the
   two existing period families. `--font-body` (the ambient default) now points at VT323; Inter
   Variable is no longer imported anywhere.
4. **Notifications** — `useNotificationStore` + `NotificationCenter`, hard-bordered/no-blur, 3-
   entry cap, error sticky by default, ~4s auto-dismiss otherwise. Verifiable via Settings →
   Notifications.
5. **Cursors** — Move and Hourglass generated, completing all six frozen roles. Move fixes a
   disclosed M4 placeholder; Hourglass wired to the existing Architect busy state via a
   globals.css-only addition.
6. **Sounds** — vocabulary mapping documented in `lib/sounds.ts`; notifications play
   success/error through the existing gated hook.
7. **Boot language** — staged `INITIALIZING...` / `LOADING MODULES...` / `READY.` copy.
8. **Docs** — `DESIGN_CONSTITUTION.md` and `TYPOGRAPHY.md` now state the above as frozen rules,
   plus the conflict-resolution hierarchy, historical-reference rule, and forbidden-patterns list.
