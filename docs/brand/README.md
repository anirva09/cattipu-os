# Brand Assets

**The marks live in `public/logo/`.** Seven files, each distinct:

| File | Use |
|---|---|
| `boot-lockup.png` | the boot screen lockup |
| `icon-color.png` | the full-colour thumb |
| `icon-haloed.png` | the thumb inside its embossed badge — the top bar |
| `icon-mono.png` | single-colour thumb |
| `lockup-mono.png` | single-colour lockup |
| `mark-navy.png`, `mark-white.png` | the mark on light and dark grounds |

Never recreate or stretch the logo. Reuse these files.

---

This folder used to hold seven more PNGs — `favicon`, `palette`,
`thumb-hero`, `thumb-mark`, `thumb-topbar`, `typography-reference`,
`wordmark-horizontal` — described here as "the single source of truth for
CATTIPU branding".

**Every one of them was zero bytes**, added as placeholders in the
foundation commit and never filled. They were removed in the canonical
consolidation, along with the sentence that pointed future sprints at
them. A folder that claims to be the source of truth while holding seven
empty files is worse than no folder: it sends someone looking in the
wrong place and hands them nothing when they get there.
