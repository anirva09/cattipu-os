# M22.5 Command Center — Sprint Handoff

**Status:** planning only. No Command Center code exists yet. Do not start M22.5 until the
owner approves it.

## Purpose

Create CATTIPU's canonical command layer and make the top-bar Search open it.

```text
Shell / Search (TopBar)
      ↓
Command Center          (one shell utility surface, like the Notification Center)
      ↓
canonical Command Registry
      ↓
existing owners: project store · filesystem store · WindowManager · settings store
```

The Command Center owns no domain state. Every command calls an action that an existing owner
already exposes.

### What must NOT be revived

- `components/CommandPalette/CommandPalette.tsx`: the legacy palette. It is unmounted, it
  calls the legacy window store at runtime, and it draws the legacy M13 icon set
  (`components/Icons`).
- `store/useWindowStore.ts`: the legacy window store, which is unmounted. `lib/apps.ts` and
  `lib/os/extensions.ts` still import its `AppId` type. Diagnostics already reports this as
  `windows.legacy-store-consumers` (degraded).
- `lib/apps.ts` `APP_MAP` as an app registry. It is legacy and still used only for
  `PlaceholderApp` copy. Do not grow it into a second app or command registry.

Removing these is a candidate cleanup inside M22.5, and only as part of replacing their one
live purpose. Nothing else may be removed on the way.

## Likely M22.5 scope

1. A canonical command contract: `id`, `label`, `group`, optional PixelForge `icon`,
   optional `keywords`, `when` (availability) and `run`, all deterministic and
   provider-free.
2. A canonical command registry in `lib/` (not in a component). It is built from the owners
   above and reuses `MENU_COMMANDS` labels.
3. The Command Center surface: a shell utility panel in the Notification Center pattern. It
   uses the existing menu/row grammar, a `cattipu-field` input and the CATTIPU chrome.
4. The top-bar Search opens it. This wires the unused `onSearch`, gives Search the
   pressed-key state while the Command Center is open, and returns focus on close.
5. A keyboard shortcut that avoids the Ctrl+Alt+C/T/R set.
6. Commands:
   - Projects: new, new from template, open, rename, archive.
   - Filesystem: new folder, new project shortcut.
   - WindowManager: open each app, cascade, tile, restore all, close or minimize the
     active window.
   - Settings: open a section, toggle sound.
7. Deterministic filtering and ranking, pure and unit-tested. No fuzzy AI matching.
8. Keyboard navigation: ↑/↓/Home/End, Enter to run, Esc to close. Match the ContextMenu
   behaviour.
9. PixelForge 16px marks on command rows.
10. Recent commands only if clearly justified. They would be session-scoped, owned by the
    Command Center and not persisted without a reason.
11. Tests: registry integrity (unique ids, every command's owner action exists, every icon
    is a registered mark), filter determinism, and a guard that the Command Center does not
    import the legacy palette or legacy stores.
